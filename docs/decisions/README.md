# Decisiones

Una decisión por archivo, numerada (`0001-titulo-corto.md`) y breve. Se registran las decisiones que afectan a varias partes del proyecto o que no son evidentes al leer el código.

## Plantilla

```
# NNNN · Título

- Estado: propuesta | aceptada | sustituida por NNNN
- Fecha: AAAA-MM-DD

## Contexto
Qué problema hay y qué lo condiciona.

## Decisión
Qué se hace.

## Consecuencias
Qué cambia, qué se gana y qué se pierde.
```
